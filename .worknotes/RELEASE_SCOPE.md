# Colors 첫 공개 범위

상태: 2026-09-30 goal 지시 반영

이 문서의 첫 공개 범위는 이전 PRODUCT_PLAN.md와 WIREFRAMES.md에서
사진 업로드를 첫 단계에 둔 권장안보다 우선한다. 전체 제품 목표에서
사진 기능을 제거한 것은 아니다.

## 이번 릴리스에서 동작할 기능

- 콘셉트 또는 HEX 기준색으로 결정적인 5색 팔레트 후보 3개 생성
- 조화 유형 선택, 원본색 편집·잠금·순서 변경, 잠긴 기준색 보존
- 웹·발행물·PowerPoint·편집기·터미널의 역할 배정과 화면 시안
- 실제 전경·배경 대비 계산, 미달 경고, 사용자가 선택하는 수정안
- 브라우저 안 프로젝트 저장·재열기, 프로젝트 JSON 가져오기·내보내기,
  화면용 CSS 변수 내보내기
- 반응형 배치, 키보드 동작, 입력·저장·가져오기 오류 안내

## 이번 릴리스에서 표시만 할 항목

- 사진 파일 업로드·사진 파일 다운로드·인터넷 사진 검색·색 추출
- 외부 파일 저장소, 계정 동기화, 공개 갤러리
- 대상 프로그램별 가져오기 검증을 통과하지 않은 전용 테마 파일

메뉴는 `준비 중`이라고 명확히 표시하고 파일 선택기나 요청을 열지 않는다.
사진 파일의 영속 저장·권리·처리 정책은 후속 작업으로 남긴다.
프로젝트 JSON·CSS는 앱이 브라우저에서 생성하는 색상 데이터이므로
이번 릴리스의 내보내기 대상이다.

## 출시 완료 기준

1. 설계·구현·코드 리뷰·자동화 테스트·브라우저 QA 결과를 기록한다.
2. 잠긴 색, 출처, 역할 덮어쓰기, JSON 왕복, CSS 결과를 확인한다.
3. 프로덕션 빌드를 통과하고 GitHub에 버전 태그·Release를 게시한다.
4. Vercel 프로덕션 URL에서 핵심 흐름과 모바일 화면을 다시 확인한다.
5. 테스트하지 않은 전용 파일을 지원 완료로 표시하지 않는다.
