# Colors v0.2.0

하나 이상의 입력색과 조합 의도에서 팔레트·colormap 후보를 만든다. 색마다
고정 여부를 선택하며 유연색은 원색 기준 한계 안에서 보정하고 되돌릴 수 있다.
새 후보 생성과 현재 결과 채택을 분리했다.

16개 이야기 레시피, Light/Dark, 여러 색상환·표색계, 가색/감색 근사,
Warm/Cool·Tint와 명도·채도·면적 조정, 적용 맥락과 최대 5개 장면을 추가했다.
역할 대비/수동 색 유지와 저장소 이행을 보완했고, 토큰·테마·색표·colormap·LUT 출력을 제공한다.

사진 서비스·ICC 인쇄·물리 안료·유료 색표·Figma 플러그인은 후속 범위다.
프로그램 파일의 구조/색값은 검사했으나 실제 외부 도구 import는 미검증이다.
명세/검토/검증은 UPGRADE_SPEC, reviews/DECISIONS, UPGRADE_QA를 참조한다.
