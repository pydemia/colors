# Colors v0.1.0

첫 공개 버전입니다. 콘셉트와 기준색에서 다섯 색의 팔레트를 만들고 실제 사용처의 역할을 설계할 수 있습니다.

## 주요 기능

- 3개 후보 생성, 기준색 잠금·편집·재생성, 사용처별 역할색 지정
- 웹·화면용 발행물·PowerPoint·코드 편집기·터미널 모사 시안
- 대비 수치와 역할별 수정 제안
- 브라우저 자동 저장, 프로젝트 JSON 가져오기·내보내기, CSS 변수 내보내기

## 현재 제공하지 않는 기능

사진 업로드·다운로드·검색·추출과 파일 저장소는 `준비 중`입니다. 프로그램별 전용 테마 파일은 실제 가져오기 검증 후 제공합니다. 모사 시안은 대상 프로그램의 실제 렌더링 보증이 아닙니다.

## 검증

TypeScript·Vite 빌드, 자동화 테스트, 데스크톱 Chromium·모바일 WebKit 브라우저 흐름을 확인했습니다. 프롬프트 품질 비교와 프로그램별 테마 파일 가져오기는 수행하지 않았습니다.
